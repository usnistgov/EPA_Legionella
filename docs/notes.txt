General notes:
	1. Goal: Replace the single “n=#” that currently represents the total events for a temperature group with a per‑bin count
		(e.g., Bin 0 n=…, Bin 1 n=…, Bin 2 n=…). This allows readers to see how many events contributed to each particle‑size bin directly on the plot.
		Current behavior: _build_temp_stats() stores one count per config_key (temp_stats[temp]["n"]), and _annotate_temp_groups() (and the companion markdown) print that single value.
		Desired behavior: Compute a separate count for each bin displayed in the figure (bins 0‑2, 3‑6, 7‑11) and format the annotation as, for example:
		Bath Door Open (Fan On)
		Bin0 n=#
		Bin1 n=#
		Bin2 n=#
		RH=51%
	2. Limit figures to the 4.1 – 5.6 LPM flow‑rate range
		Goal: Exclude any events whose recorded flow rate falls outside 4.1–5.6 LPM so that all existing box‑plot figures (e.g., *_bin0-2.png, *_bin3-6.png, *_bin7-11.png) only display data from runs within that flow‑rate window.
		Current behavior: The plotting functions use the full results_df without filtering on flow rate.
		Desired behavior: Apply a filter 4.1 ≤ flow_rate_lpm ≤ 5.6 to results_df before any statistics are built or plots are drawn. In the future, the same filter logic can be parameterised (e.g., flow_range=(low, high)) to generate figures that specifically target other flow‑rate ranges.
	3. Update mannequin figures to four panels (narrow / wide × with / without mannequin)
		Goal: Replace the current two mannequin‑related plots (one “no mannequin”, one “with mannequin”) with four separate figures that also differentiate shower‑head geometry.
		Current behavior: Each figure aggregates data for all shower‑head types, showing either the “no mannequin” or “with mannequin” case.
		Desired behavior:
		No mannequin – Narrow shower head
		No mannequin – Wide shower head
		With mannequin – Narrow shower head
		With mannequin – Wide shower head
		All four plots should use the same underlying dataset (the existing “with” and “without” mannequin data) but apply an additional filter on the shower_head_type (or equivalent column) to separate narrow and wide configurations. This will give a clear visual comparison of how mannequin presence and shower‑head size each affect the results.
	4. Remove “Pepco Mid” from spray‑pattern, shower‑head, and head‑type figures
		Goal: Exclude any events whose config_key contains “_PepcoMid” (or similar) from the three sets of figures that display spray‑pattern, shower‑head, and head‑type results.
		Current behavior: The plotting functions for these figures include all configurations, so the “Pepco Mid” data appears alongside the other cases.
		Desired behavior: Filter the DataFrame used for each of those figure‑generation pipelines with a condition such as ~df["config_key"].str.contains("_PepcoMid") before any statistics are computed or plots are drawn, thereby removing the Pepco Mid data from the final visualizations.
